# Calculadora de Conversão Energética — Supergasbras

Compara o custo do GLP com o combustível que o cliente usa hoje.

- **Simulador:** mesma lógica da aba Simulador da planilha. Equivalência pelo poder calorífico (PCI), custo mensal, economia mensal e anual e percentual de economia.
- **Estudo de conversão:** acrescenta eficiência de queima, energia elétrica, manutenção, créditos de PIS/COFINS e ICMS e payback do investimento.
- **Tabela de PCI:** 82 combustíveis da aba Dados da planilha.

É uma página única (`index.html`), sem dependências. Para publicar, ative o GitHub Pages em **Settings → Pages → Deploy from a branch → main / (root)**.
